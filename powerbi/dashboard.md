## 📌 About the Dashboard

This interactive Power BI dashboard is built on top of a Gold-layer semantic model created using Microsoft Fabric. It provides business insights from integrated CRM and ERP datasets.

---

## 📈 Key Features

### 🧭 Executive Overview
- Total Sales: 29M+
- Total Orders: 28K+
- Total Customers: 18K+
- Average Order Value: 1.06K
- Sales trend analysis over time
- Category-wise sales distribution

---

### 📦 Product Analysis
- Sales by category & subcategory
- Top & Bottom performing products
- Product Cost vs Sales analysis
- Profit and Profit Margin insights

---

### 👥 Customer Insights
- Sales distribution by country
- Gender-wise sales contribution
- Customer growth trend over time
- Top 10 customers by sales

---

## 🧠 Data Model

- Built using *Star Schema*
- Fact Table: fact_sales
- Dimension Tables:
  - dim_customer
  - dim_product
- Separate *Measures Table* for KPI calculations

---

## ⚙️ Technologies Used

- Microsoft Fabric (Lakehouse + Warehouse + Pipelines)
- SQL (Data Transformation)
- Power BI (Visualization)
- DAX (Measures & KPIs)

---

## 🚀 How to Use

1. Open the dashboard link above  
2. Use filters (Year, Country) for analysis  
3. Navigate between pages:
   - Executive Overview  
   - Product Analysis  
   - Customer Insights
